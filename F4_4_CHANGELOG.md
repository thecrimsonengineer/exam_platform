# F4.4 Change Log

- Practice Questions is established as the primary authoring hub.
- Added Studio manual Create/Edit workflow.
- Added Studio Complete Question Paste workflow using the existing parser.
- Added Studio JSON file import using `file_selector`.
- Added canonical Studio import conversion service.
- JSON imports automatically receive the selected Studio context.
- JSON imports enter as Draft and must pass the same quality validation before import.
- Added Edit, Publish, Delete and Refresh actions to the Studio question list.
- Removed the Studio dependency on the legacy Question Bank screen for question editing.
- Added Studio ownership of the Answer Length Check control.
- Preserved the five-published minimum with no maximum question count.
- Preserved `LocalQuestionRepository` as the question source of truth.
