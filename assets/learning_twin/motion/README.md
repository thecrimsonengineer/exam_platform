# Learning Twin motion assets

LTAM-4 owns the runtime binding contract for this directory.

The canonical production filenames are frozen by
`docs/learning_twin/LTAM_4_MOTION_MANIFEST_STATE_MAPPER_FLUTTER_RENDERER_FOUNDATION.md`.

No placeholder animation is substituted for a missing reviewed clip. Until the
canonical Lottie files are added by the motion-asset production stream, the
LTAM-4 renderer intentionally fails closed to the existing SVG Learning Twin.
