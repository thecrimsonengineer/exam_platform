# FCP Source Policy

Status: FROZEN

FCP preserves the frozen Flashcard provenance model and authority tiers.

```text
1  federalLawRegulation

5  scholarlySupporting

99 blocked
```

Every learner-ready factual card requires:

- one or more validated source references
- exactly one primary source
- exact source locator
- verified source status
- valid definition-use mode
- valid copyright mode

Authority does not automatically imply permission for verbatim reuse.

Prefer faithful or educational paraphrase unless the registered source explicitly permits verbatim use.

Numerical and regulatory claims must retain their applicable qualifiers and context.
